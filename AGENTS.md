# Creeper Bot Project Rules

- **No Auto-Commits:** Do not automatically commit or push code unless the user explicitly asks for it. Otherwise leave changes for review.
- **Beta Build Confirmation:** Ask whether the beta build/version should be incremented only when the requested change reasonably warrants a new build, such as a user-facing feature, behavior change, or release-bound fix. Do not ask for documentation-only edits, internal maintenance, diagnostics, or other changes that would not normally trigger a release.
